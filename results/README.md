# Results

JSON and NPZ files behind Fig. 5 and Supplementary Sections S.5-S.6.

Model names in the files: `mpa0` = MACE-MPA-0, `v1` = FIRE, `v2` = FIRE+SR, `v21` = FIRE+SR', `v22` = FIRE+SR'+3B,
`ft` = fine-tuned model of the respective system.

The LiCl/GaF3 entries of `g2x_report.json`, `hunt100_LiClGaF3_*.json`, `hunt100_part_LiClGaF3_*.json` and the
LiCl/GaF3 runs in `grid/` were computed with an earlier 82-frame checkpoint and are not used in the paper.
`kdimer_model.json` contains the LiCl/GaF3 dimer curves of the model of Fig. 2; `kdimer_model_results1.json`
keeps the earlier values and `kdimer_LiClGaF3_itertwo.json` the recomputation.
